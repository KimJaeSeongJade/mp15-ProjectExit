# 기술문서 - 퍼즐 클리어 판정

게임의 핵심 매커니즘인 퍼즐들이 클리어 되었는지를 판정하기 위한 기능입니다.
이 문서에서 세부 코드는 다루지 않으며, 어떤 구조로 설계되었는지를 다룹니다.
