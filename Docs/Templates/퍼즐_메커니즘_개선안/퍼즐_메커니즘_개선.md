# 프로젝트 명 : Dog_Maze_Escape (가제)

## 개요

귀여운 강아지가 몬스터를 피해 퍼즐을 완수하고 탈출구를 찾아야 합니다.
화살표를 따라 퍼즐에 도달하여 퍼즐을 해결하고, 필드를 돌아다니며 가끔식 마주치게 되는 수상한 작은 큐브들도 무시하지 마세요.

## 1. 게임 전체 플로우

![[Pasted image 20260922134118.png]]

1. 게임 시작
2. 화면에 나타난 화살표 UI를 따라 퍼즐 A나 B의 구역으로 이동한다.
   2.1. 이동 중 `KeyItem` 획득 시 화살표 UI > 퍼즐 C로 향한다.
3. `KeyItem` 보유 중이 아닐 경우 화살표 UI는 
   **클리어 되지 않은 가장 가까운 퍼즐**을 가리킨다.
4. 퍼즐 A, B, C의 목록이 적힌 UI가 있고 클리어한/ 하지 못 한 퍼즐 확인이 가능
5. 모든 퍼즐을 해결하고 `게임 시작 장소`로 되돌아오면 바닥이 사라지고 `큰 구멍`이 생성되어 있다.
6. 구멍으로 걸어가 떨어지면 게임 클리어

# 2. 퍼즐 메커니즘 (개선)

## 2.1. 퍼즐 A : 발판 밟기

1. 퍼즐 구역에 도달하면 바닥에 6개의 발판(=`Platform`)이 있다.
   (납작한 정사각형/ 하얀색/ 점프없이 올라감/ 밟아도 눌리지 않음)
2. 퍼즐 발판 근처에 6가지 색상과 그 순서에 대한 힌트가 적힌 표지판이 있다.
3. 발판에 올라서면 발판이 예정된 색상으로 변한다. 제한시간 2~3초 뒤 초기화
4. 제한시간 내에 다음 발판을 밟으며 모든 순서에 맞게 모든 발판을 밟아야한다.
   \[올바른 순서라면\] 다음 발판을 밟으면 제한시간 초기화.
   \[잘못된 순서라면\] 다음 발판을 밟으면 1~2초간 밟은 `Platform`을 포함한 모든 발판의 색상을 유지하다가 전부 초기화
5. 힌트에 적힌 의도(순서)대로 모든 `Platform`을 밟으면 퍼즐 클리어
   (퍼즐을 클리어하면 발판 색상은 초기화 되지 않고 영구히 유지)

![[Pasted image 20260922132942.png]]

## 2.2. 퍼즐 B : 블록 테트리스
1. 퍼즐 구역에 도달하면 퍼즐의 중심이 되는 바닥판 `Tile`이 있다.
   (1\*1 사이즈의 칸이 3\*3으로 9칸 / 칸은 이미지 등으로 9칸임을 알 수 있게 표현)
2. `Tile` 옆에는 8가지 서로다른 모양의 블록 (`Block`)이 있다.
3. 플레이어는 블록을 잡고 `Tile`위로 옮길 수 있다.
   (퍼즐 구역 밖으로는 블록을 잡고 나갈 수 없다)
4. 3\*3 `Tile`모양에 정확하게 맞춰 블록을 옮기면 퍼즐 클리어
   (블록은 `Tile`위에 올려놓았을 때 위치가 고정되지 않음 / `Tile`을 모두 채워도 밖으로 튀어나와있는 블록이 있다면 클리어되지 않는다)

## 2.3. 퍼즐 C : Key Item 찾기

1. 해당 퍼즐은 화살표 UI가 기본적으로 가리키지 않는 상태이다.
2. 필드에 흩뿌려져 있는 3개의 `KeyItem`이 존재한다.
3. 플레이어가 게임 진행 중 언제든 `KeyItem`을 발견해 버튼을 눌러 상호작용하면 손에 들고 있는 상태가 된다.
4. 화살표 UI는 `KeyItem`을 들고 있는 중에 열쇠구멍(`KeyHole`)을 가리키게 된다.
   - 퍼즐 A와 B를 진행중일 때 : 화살표의 방향이 `KeyHole`을 최우선으로
   - 퍼즐 A, B를 모두 클리어 한 경우 : 다시 활성화 되어 `KeyHole`을 가리키도록
1. 플레이어는 `KeyHole`까지 안전하게 도달하여 `KeyHole`과 상호작용하여 `KeyItem`을 끼워넣어야한다.
2. `KeyItem` 3개가 전부 `KeyHole`에 모이면 퍼즐 클리어

## 2.4. 최종 미션

1. 퍼즐 A, B, C를 모두 클리어한 경우 화살표 UI는 플레이어의 게임 시작 시 위치를 가리킨다.
2. 화살표 UI를 따라 시작지점으로 되돌아가면 시작 지점에 거대한 싱크홀과 같은 구멍이 생성되어 있는 상태이다. (바닥이 사라진 것)
3. 구멍으로 걸어가 떨어지면 게임 클리어
