## 2. 컨셉

- Low-Poly 기반의 화사한 그래픽톤을 사용합니다.
- 다수 몬스터의 시야를 피해 퍼즐(미션)을 수행합니다.
- 모든 퍼즐을 완료한 뒤 탈출구에 도달하면 클리어합니다.
- 몬스터의 감지는 단순 범위가 아니라 **부채꼴 시야**를 기준으로 합니다. 발각되면 도망치면서 남은 미션을 마쳐야 합니다.

### 하지 않는 것

정해 두지 않으면 계속 이야기가 나오는 항목입니다.

- <mark>멀티플레이는 넣지 않습니다.</mark> 서버를 도입할 시간이 없습니다. 긴장감은 몬스터 수로 만듭니다.
- 세이브/로드는 넣지 않습니다.
- 난이도 선택, 스테이지 여러 개는 넣지 않습니다. 맵 하나를 제대로 완성합니다.

## 5. 씬 구성과 소유자

<mark>씬은 소유자만 저장합니다.</mark> 다른 사람은 열어서 확인만 하고 저장하지 않습니다. 이유는 `Unity/ProjectRules.md` 에 있습니다.

| 씬 | 용도 | 소유자 |
|---|---|---|
| `Title` | 타이틀 화면 | (기입) |
| `InGame` | 인게임 | (기입) |

본인이 만드는 기능을 시험할 때는 `Assets/Scenes/Test/` 아래에 **본인 이름으로 테스트 씬**을 만들어 씁니다. 테스트 씬은 빌드에 포함하지 않습니다.

## 6. UI 구성

- **타이틀**: 타이틀 로고와 배경, 시작, 종료
- **인게임**: 일시정지 팝업(이어하기 / 타이틀 복귀), 플레이어 체력, 주변 몬스터 거리에 따른 표시 변화
- **인게임 월드스페이스**: 퍼즐 진행도, 플레이어 하단에 가장 가까운 미션 방향 표시

## 7. 클리어 조건

- 필드의 퍼즐(미션)을 모두 완료합니다.
- 완료 후 탈출구에 도달하면 클리어합니다.
- 플레이어 체력이 0이 되면 실패합니다.
