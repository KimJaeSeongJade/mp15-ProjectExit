# (프로젝트명)

메타플밍 15기 추석기간 사이드프로젝트. 다수 몬스터의 시야를 피해 퍼즐을 수행하고 탈출하는 3인칭 게임입니다.

## 현재 상태

- 진행 기간: 2026-09-19(토) ~ 2026-09-27(일)
- 발표회: 2026-09-28(월)
- 현재 단계: (작업 중 / 기능 동결 / 발표 준비 중 - 해당하는 것만 남깁니다)

## 환경

| 항목 | 값 |
|---|---|
| 엔진 | Unity 2022.3 LTS |
| 렌더 파이프라인 | Built-in Render Pipeline |
| 입력 | Input Manager |
| 플랫폼 | Windows |

버전이 다르면 프로젝트가 열리지 않거나 설정이 깨집니다. Unity Hub에서 같은 버전을 설치한 뒤 여십시오.

## 처음 받았다면

1. GitHub Desktop으로 이 저장소를 클론합니다.
2. Unity Hub에서 `Add` 로 클론한 폴더를 추가하고 엽니다.
3. `Docs/README.md` 를 열어 문서 읽는 순서를 따릅니다.

## 팀

강성현, 노승훈, 류승민, 손예슬, 정재윤 (지도: 김재성 강사)

## 문서

프로젝트의 모든 규칙과 기록은 `Docs/` 에 있습니다. 시작점은 `Docs/README.md` 입니다.
